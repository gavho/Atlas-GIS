# Sample data (synthetic, not real data)

Generated by `node scripts/make-samples.mjs`. Positions are rough and made up (around O'Hare, so they work with the ORD GIS Area preset).

| File | Format | Tests |
|---|---|---|
| alp_sample.zip | Shapefile (EPSG:3435, with .prj) | zipped SHP + reprojection |
| alp_noprj/ | Shapefile parts, **no .prj** | loose-file grouping + CRS dialog (pick EPSG:3435) |
| projects_sample.kmz | KMZ | KMZ unzip, ExtendedData, M/D/YYYY dates as text |
| construction.geojson | GeoJSON | ISO dates (date fields), numbers, open-ended values |
| navaids.csv | CSV (Lat/Long) | CSV lat/lon detection |

Good things to try: double-click a polygon to edit it, add a field from the table's **+ Field**, edit a cell, export the layer as a Shapefile and open the zip again.
